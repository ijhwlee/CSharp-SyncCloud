- Explained sync modes:

  - `--mode to-local`: copy from OneDrive/cloud to local.
  - `--mode to-cloud`: copy from local to OneDrive/cloud.

- Recorded accepted mode aliases:
  - `sync`, `both`
  - `local`, `tolocal`
  - `cloud`, `tocloud`

- Explained checkbox-style options:
  - `--remove-cloud`, `--remove-cloud=true`, and `--no-remove-cloud` map to the `RemoveCloud` check box.
  - `--show-copy-only`, `--copy-only`, `--show-copy-only=false`, and `--no-show-copy-only` map to the `showCopyOnly` check box.

- Emphasized that `--show-copy-only` is not a dry run. It only reduces progress output by suppressing checking messages.
- Emphasized that `--remove-cloud` is destructive and only deletes cloud files after a successful copy in `--mode to-local`.
